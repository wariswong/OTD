# incoming/ — จุดวางโค้ดใหม่ (ไฟล์ดิบ)

วางไฟล์โค้ดรุ่นใหม่ที่นี่ แล้วบอก Claude ว่า "มีโค้ดใหม่ใน incoming/" — Claude จะปรับให้ใช้กับระบบได้
ตามขั้นตอนใน [`docs/NEW_CODE_INTEGRATION_GUIDE.md`](../docs/NEW_CODE_INTEGRATION_GUIDE.md)

## ตั้งชื่อไฟล์

`<ชื่อเดิม>_<วัน><เดือน><ปี ค.ศ.>.py` เช่น `PhaseOptimizer_17092026.py` = 17 ก.ย. 2026
(ชื่อต้นทางต้องขึ้นต้นเหมือนไฟล์เดิม เพื่อให้รู้ว่าเป็นของฟีเจอร์ไหน — ดูตารางในคู่มือ)

## กติกา

- ไฟล์ในโฟลเดอร์นี้ **ไม่ถูก commit** (ดู `.gitignore`) — ผลที่ปรับแล้วจึงจะเข้า git
- ถ้าจะแก้ไฟล์เดิมทับชื่อเดิม ให้วางที่นี่แทนการเขียนทับไฟล์ใน `feature_*/` โดยตรง จะได้ diff กับรุ่นก่อนหน้าได้ชัด
- ประมวลผลเสร็จแล้ว Claude จะย้ายไฟล์ดิบไป `incoming/_processed/` (เก็บไว้ในเครื่อง ใช้เทียบย้อนหลังได้)
